  - title: How to Open Update Preferences
    body: |
      There are **two ways** to access [Update Games and Equipment](https://mindjam.my.site.com/Portal/s/update-preferences).

      *Option 1:*

      - Go to [**My Account**](https://mindjam.my.site.com/Portal/s/comm-my-account)
      - Click **My Account** again
      - In the top right, click **Update Games and Equipment** Flow

      ![Update Games and Equipment flow prompt](../assets/images/update-games-equipment-preferences/update-games-equipment-flow-prompt.png)

      *Option 2:*

      - Go to the [**Home Page**](https://mindjam.my.site.com/Portal/s/)
      - Scroll to the bottom
      - Click **Update Preferences**

      This will open the **Update Games and Equipment** flow.
    media:
      - src: assets/images/update-games-equipment-preferences/update-preferences-tile.png
        alt: Update Preferences tile on the home page
  - title: What a Flow Means
    body: |
      A flow in Salesforce is a **step-by-step form** that guides you through a process. In this case, it simply asks you to enter information about your: games, equipment, interests, skills, preferences. Click **Next** to begin.
    media:
      - src: assets/images/update-games-equipment-preferences/flow.png
        alt: Start of the Update Preferences flow
  - title: "Step 1: Add Your Games"
    body: |
      You will first see a list of games. Tick the games you currently have access to. If you have access to any of MindJam's most commonly used games, please make sure you tick them where relevant, including:

      - Roblox
      - Fortnite
      - Minecraft Java
      - Minecraft Bedrock

      If a game you use is not listed, use the **Other Games** free text box to add it.
  - title: "Step 2: Add Your Equipment"
    body: |
      Next, tick the equipment that is relevant to you. If something you use is not listed, use the **Other Equipment** free text box to add it. Equipment options will be updated over time.
  - title: "Step 3: Add Other Information"
    body: |
      You will then be asked for some additional information. This is to help assigning find better and more suitable mentee matches for you.

      - *Gender Identity* — You can complete this if you want to. There is also a **Prefer not to say** option.
      - *Interests* — Add any interests you would like to include.
      - *Other Games* — There is another box where you can add extra games if you forgot any earlier.
  - title: "Step 4: Add Your Skills"
    body: |
      You will also see a section called **Mentor Skills**. This uses a **dual list box**. To complete this: click the skills that apply to you, click the arrow to move them into the chosen section. Only move across the skills that are relevant to you.
  - title: Finish the Form
    body: |
      When you have completed everything, you will see a message confirming that your preferences have been updated. Click **Finish**.
    media:
      - src: assets/images/update-games-equipment-preferences/update-equipment-selection.webm
        alt: Completing the Update Preferences flow
  - title: Keeping It Up to Date
    body: |
      You can update your preferences at any time. **We recommend updating** them if:

      - you start using a new console
      - you get access to a new game
      - your equipment changes
      - your skills change

      If there is a game or piece of equipment that should be added to the list, please let senior leadership know so it can be reviewed.
