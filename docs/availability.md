steps:
  - title: Why Availability Matters
    body: |
      Once you have updated your games, equipment and preferences, the next step is to set your availability. In Salesforce, this is called [operating hours](https://mindjam.my.site.com/Portal/s/operating-hours), and it tells the system and the assigning team when you want to work. If you do not want to work on a particular day or time, simply do not add that time slot — any time in your availability that is not already blocked by a session can appear as available for matching.
  - title: Example
    body: |
      If you usually work on Monday from 9:00 to 5:00, but take a break from 1:00 to 2:00, you would enter:

      - 9:00 to 1:00
      - 2:00 to 5:00

      This ensures 1:00 to 2:00 does not appear as available.
  - title: How to Add Availability
    body: |
      - Log in to the Community Site
      - Go to **Appointment Management**
      - Open **Manage Time Slots**
      - Click the link with your name
      - Click **New**

      A new window will open. From here:

      - Choose the day of the week
      - Leave Type as **Normal**
      - Enter the start time
      - Enter the end time
      - Click **Save** or **Save & New**

      If you are adding more than one time slot, **Save & New** is usually the easiest option.
    media:

  - title: Using the Example Above
    body: |
      *To add Monday 9:00 to 1:00:* Day of the Week: Monday; Type: Normal; Start Time: 9:00; End Time: 1:00. Then click **Save & New**.

      *To add Monday 2:00 to 5:00:* Day of the Week: Monday; Type: Normal; Start Time: 2:00; End Time: 5:00. Then click **Save**.

      Repeat this for any other days and times you want to add.

  - title: Updating Availability Later
    body: |
      If your availability changes, you can go back into **Manage Time Slots** and add new time slots at any time. To edit, delete, or clone a time slot:

      - Find the day and time you want to change
      - Click the small **(▼)** arrow icon next to it
      - Choose **Edit**, **Delete**, or **Clone**
  - title: Optional Alternative Method

    body: |
      There is another way to do this, but it is a little more clunky. Instead of entering separate working slots, you can:

      - Add your full working day in Manage Time Slots
      - Go to your calendar
      - Add a new event for the time you do not want to work
      - Set the event type to **Personal Time**
      - Set it to repeat weekly if needed

      For example, if you work 9:00 to 5:00 but want 1:00 to 2:00 blocked out, you could add availability for 9:00 to 5:00, then add a Personal Time event from 1:00 to 2:00. This works because the blocked time will not appear as available. You do not need to call the event Lunch. You can call it something simple like **Blocker**.
    media:
      - src: assets/images/availability/timeslot3.png
        alt: Personal Time calendar event used as a blocker
  - title: Important
    body: |
      If you use the calendar blocker method and forget to add the blocker, the system may treat that time as available. **This could mean you appear free for times you did not want to offer.** For most people, the clearest option is to enter availability as separate time slots.
