steps:
  - title: Overview
    body: |
      To access your [sessions](https://mindjam.my.site.com/Portal/s/my-appointments), go to **Appointment Management** and then click **Sessions**.
  - title: Session List Views
    body: |
      At first, this page may open in the Recently Viewed list. To see other session views, click the dropdown arrow next to **Recently Viewed**. This lets you switch between different filtered views of your sessions.
  - title: Why List Views Are Useful
    body: |
      List views make it much easier to find the sessions you need without searching through everything. For example, instead of looking through every session in the system, you can choose a view that only shows:

      - today's sessions
      - sessions that still need wrapping up
      - new mentees that need confirmation
    media:
      - src: assets/images/accessing-your-sessions/view-session-list-views.webm
        alt: Switching between session list views
  - title: Useful List Views — Requiring Confirmation New Mentee
    body: |
      This is a useful way to keep track of new mentees. It shows young people who may still need to be accepted or rejected.
    media:
      - src: assets/images/accessing-your-sessions/open-session-from-mentee-profile.webm
        alt: Opening a session from a mentee profile
  - title: More Useful List Views — Requiring Wrap Up Today
    body: |
      This shows all the sessions you have today that have not been wrapped up yet. This can be especially helpful at the end of the day when checking what still needs to be completed.

      *Other Views:* There may also be other helpful views depending on what has been set up in Salesforce. Some of these list views may be changed over time, depending on what is most useful.
    media:
      - src: assets/images/accessing-your-sessions/wrap-up-a-session-from-today.webm
        alt: Wrapping up a session from the Requiring Wrap Up Today view
  - title: Opening a Session
    body: |
      From any list view, click on the hyperlink that starts with **"SA"** to open it. From there, you can check the session details and wrap up the session if needed.
  - title: Key Point
    body: |
      Session list views are one of the quickest ways to keep track of what needs attention. Use them to find upcoming sessions, sessions needing wrap up, and mentees needing confirmation.
