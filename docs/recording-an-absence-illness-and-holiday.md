steps:
  - title: Overview
    body: |
      If you are going to be away, you can record this in Salesforce so it is visible to the team. If you need sessions to be **cancelled**, you will need to cancel them **manually**. This [absence](https://mindjam.my.site.com/Portal/s/absences) record is mainly there so **Senior Leadership** can see that you are away. For example, if a **parent** or **carer** gets in touch while you are on **holiday** or **unwell**, the team can check this first and avoid contacting you unnecessarily.
  - title: How to Add an Absence
    body: |
      To record an **absence**:

      - go to **Appointment Management**
      - open **Absences**
      - click **New**
      - enter the details
      - click **Save**

      Your absence will then be added to the system.
  - title: What This Is Used For
    body: |
      This does not automatically cancel sessions for you. Instead, it is mainly used so the **Senior Leadership** team can see that you are unavailable. This helps avoid confusion if someone tries to contact you while you are away.
  - title: Useful Tip
    body: |
      If you use this section regularly, it can help to pin the most useful view. Select **My Absences**, pin that view. This makes it quicker to return to your own absence records later.
    media:
      - src: assets/images/recording-an-absence/log-illness-absence.gif
        alt: Pinning the My Absences view for quicker access
  - title: Key Point
    body: |
      Record your absence in the system so the team can see you are away, but remember to cancel any sessions separately if needed.
