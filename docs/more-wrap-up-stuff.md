title: More Wrap Up Stuff
section: understanding-the-difference
description: How to cancel a session in advance and how to pause a repeating session for planned breaks.
steps:
  - title: If You Need to Cancel a Session
    body: |
      If a session needs to be cancelled in advance, you do not need to wrap it up. Instead:

      - Open the **Service Appointment**
      - Click **Cancel Session**
      - Add the reason
      - Follow the steps on screen

      You will be asked for:

      - an internal cancellation note — this will not be shared in any attendance emails
      - a cancellation reason from a dropdown — this will be shared in any attendance emails
    media:
      - src: assets/images/wrap-up-a-session/open-session-recording.webm
        alt: Opening the session recording and starting a cancellation
  - title: Did Not Attend
    body: |
      To mark a session as **Did Not Attend**, open the **Appointment Status** dropdown and select **Did Not Attend**.

      If the parent or LA does not let you know they need to cancel, or they let you know too late for it to count as a normal cancellation, select **Late Notice Cancellation** instead.

      Both options still charge the parent or LA, and you will still be paid for the session.
    media:
      - src: assets/images/more-wrap-up-stuff/did-not-attend-status.png
        alt: Wrap Up Session modal with Appointment Status set to Did Not Attend
  - title: If You Need to Pause a Repeating Session
    body: |
      If you need to cancel **one session**, use the normal **Cancel Session** option above.

      If there is a planned break, such as a school holiday, annual leave, or a mentee being away for a few weeks, it may be quicker to pause the repeating pattern instead of cancelling each session one by one.

      To do this:

      - open the first session that should not go ahead
      - use **Delete Series**
      - choose the option that removes **this event and the following series**
      - set the repeating session back up again from the date sessions should restart

      This keeps the calendar cleaner and avoids you having to cancel several sessions individually.

      **Important:** only use this when the repeating sessions are stopping for a planned period. If you are only cancelling one session, use **Cancel Session** instead.

      For more detail on how **Delete Series** works, see the [Deleting an Event](../using-calendar-events/#step-8) section.
